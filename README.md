# Q-Vision3 · Organization profile

Оформление и навигация GitHub-организации [Q-Vision3](https://github.com/Q-Vision3).

- `profile/README.md` — стартовая страница организации.
- `assets/banner.svg` — баннер профиля.
- `assets/logo.svg` — векторный знак QV.

GitHub отображает `profile/README.md` из основной ветки публичного репозитория `.github`. Исходники продуктов, прошивки и ключи хранятся в своих приватных репозиториях; здесь находятся только оформление и ссылки.

При добавлении проекта обновите его карточку в `profile/README.md`. Названия ссылок должны совпадать с именами репозиториев. Изображения используют абсолютные raw-ссылки, чтобы одинаково работать в репозитории и на странице организации.

Ветка профиля: `codex/org-profile`.
